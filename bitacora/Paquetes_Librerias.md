
# Creación de redes GAN (Generative Adversial Networks)

## TensorFlow
TensorFlow es una biblioteca que sirve como modelo para la creación de redes neuronales GAN (Generative Adversial Network) en Python. 

Este modelo utiliza en concreto tres capas de neuronas para crear cada una de estas redes neuronales:
1. Capa Flatten: Capa aplanada
2. Capa Dense
3. Capa Dropout: Capa de neuronas de salida



## PyTorch
Esta biblioteca sirve para crear GANs (Generative Adversial Networks) en Python desde cero.

Tenemos un tutorial de como implementar una red neuronal de este tipo utilizando esta biblioteca en el siguiente enlace: https://www.geeksforgeeks.org/generative-adversarial-networks-gans-in-pytorch/


# Paquetes para poder trabajar con datos procedentes de PhysioNet desde Python

## WFDC (Waveform Database Software Package)
Esta biblioteca / librería nos permite trabajar con la plataforma de PhysioNet o datos procedentes de la misma en Python, sin necesidad de realizar muchas modificaciones a los datos para poder trabajar con ellos. 

En el siguiente enlace podemos encontrar una explicación detallada de esta biblioteca y de cómo podemos ponerla en uso y trabajar con ella: https://physionet.org/content/wfdb-python/3.3.0/
